# AWS Icon Guessing Game - レベル判定基準の更新

AWSサービスアイコンの知識をテストするサイバーパンク風ゲームのレベル判定基準を更新しました。

## 新しいレベル判定基準

より厳格なレベル判定基準を実装しました：

1. **AWS EXPERT（AWSエキスパート）**
   - 新基準: 10問全問正解、かつ回答時間が30秒以内
   - 完璧な知識と素早い判断力が求められる最高難度の称号

2. **AWS PROFESSIONAL（AWSプロフェッショナル）**
   - 新基準: 
     - 10問全問正解、かつ回答時間が30秒超60秒以内
     - または9問正解、かつ回答時間が60秒以内

3. **AWS ASSOCIATE（AWSアソシエイト）**
   - 新基準:
     - 10問全問正解、かつ回答時間が60秒超
     - または9問正解、かつ回答時間が60秒超
     - または8問正解、かつ回答時間が90秒以内

4. **AWS PRACTITIONER（AWSプラクティショナー）**
   - 新基準:
     - 8問正解、かつ回答時間が90秒超
     - または6-7問正解

5. **BEGINNER（ビギナー）**
   - 基準: 6問未満の正解

## 変更点の説明

- **AWS EXPERT**: 最も厳しい基準となり、全問正解かつ非常に速い回答速度が必要
- **AWS PROFESSIONAL**: 高い正確性と素早さが求められる
- **AWS ASSOCIATE**: 高い正確性が求められるが、時間的余裕がある
- **AWS PRACTITIONER**: 基本的な知識があることを示す
- **BEGINNER**: 入門レベル

## 使用方法

```bash
# 必要なパッケージのインストール
pip install pygame

# ゲームの実行
python aws_icon_game_clean_complete.py
```

## ゲームの特徴

- 30種類のAWSサービスアイコンから出題
- アイコンが上から下へ徐々に表示
- 4つの選択肢から正しいAWSサービス名を選択
- 10問の問題に回答後、スコアと回答時間に基づいてAWSレベルを判定
- 答え合わせ画面で各サービスの説明を確認可能

## 注意点

- 環境によってはPygameのインストールが必要です
- アイコンファイルは `icons` フォルダに配置する必要があります

AWS EXPERTを目指して挑戦しよう！
